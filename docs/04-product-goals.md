# Veleda — Product goals

## Brief

A consumer-facing application that makes Solana useful in everyday life: something people would genuinely want to use, with a clear audience, a real problem and a simple, working user experience. Solana should power a meaningful part of the product, not just sit behind a wallet-connect button.

## Success criteria

- Clear user need and potential for adoption.
- Ease of use, including onboarding.
- Technical execution and meaningful use of Solana.
- A working end-to-end experience.

## Deliverables

- A working demo; deployment on Solana devnet is sufficient.
- A code repository with a README and setup instructions.
- A 2–4-minute demo video.
- A clear explanation of how Solana powers the project.
